# 归并排序（Merge Sort）复习笔记

代码在 `text.c`。本文从"总体思想 → 知识点 → 逐行步骤 → 完整演示 → 易错点"讲解，方便复习。

---

## 一、一句话核心思想

**分而治之（Divide and Conquer）：先把大问题拆成小问题，小问题解决后，再合并成完整答案。**

针对排序：
1. 分：把数组从中间对半切开，一直切到"每段只有一个元素"为止。
2. 治：一段只有一个元素时，它天然就是有序的，不用再排。
3. 合：把两段各自已经有序的数组，合并成一段更大的有序数组。

## 二、用到的知识点（先扫一遍）

| 知识点 | 在本程序里的用途 |
|---|---|
| 函数 | 拆成 `merge`（负责合并）和 `merge_sort`（负责分治递归）两个函数，各干各事 |

| scanf 返回值 | 判断输入是否成功，防止读到无效数据 |

## 三、程序总体结构

```
main
 ├─ 1. 输入元素个数 n
 ├─ 2. 动态分配数组空间
 ├─ 3. 读入 n 个数
 ├─ 4. merge_sort(arr, 0, n-1)   ← 对整个数组排序
 └─ 5. 打印结果，释放内存

merge_sort(arr, left, right)        # 让 arr[left..right] 这一段变有序
 ├─ 如果 left >= right：这一段最多一个元素，直接返回（递归出口）
 ├─ mid = (left+right)/2           # 1. 分：取中点
 ├─ merge_sort(左半边)              # 2. 递归：让左半边有序
 ├─ merge_sort(右半边)              # 3. 递归：让右半边有序
 └─ merge(arr, left, mid, right)    # 4. 合：两半已有序，合并成整体有序

merge(arr, left, mid, right)        # 前提：左半和右半各自有序
 ├─ 开一块临时数组
 ├─ 双指针 i、j 谁小拷谁
 ├─ 剩下的全部拷进去
 └─ 临时数组拷回 arr，释放临时空间
```

## 四、`main` 函数逐步讲解（每一步是干嘛的）

1. `int n;` → 准备变量，存"一共几个数"。
2. `scanf("%d", &n)` → 读元素个数。
   - `scanf` 返回值是"成功读到的项数"，
   - 写成 `scanf(...) != 1`，意思是：如果没读到 1 个整数，说明输入非法 → 报错并结束。
   - 顺带判断 `n <= 0`，个数不能是 0 或负数。
3. `malloc(n * sizeof(int))` → 申请能装 n 个 int 的连续内存，返回首地址。
   - `sizeof(int)` 是因为"一个 int 占几个字节"因机器而异，不能写死。
4. `if (arr == NULL)` → malloc 可能失败（内存不够），失败返回 NULL，必须检查，否则后面会崩。
5. `for` 循环读入 n 个数，存进 `arr[0..n-1]`，每个都要检查 scanf 是否读成功。
6. `merge_sort(arr, 0, n - 1)` → 排序。`0` 是左边界，`n-1` 是右边界，表示"排整个数组"。
7. 打印排序结果。
8. `free(arr)` → 把 malloc 申请的内存还回去。**用 malloc 申请的内存必须 free，不然内存泄漏。**

## 五、`merge_sort` 逐步讲解（递归部分，重点理解）

```c
void merge_sort(int arr[], int left, int right)
{
	int mid;

	if (left >= right) {
		return;              // 出口：区间里最多一个元素，天然有序
	}

	mid = (left + right) / 2;        // 分：找中点，切成 [left..mid] 和 [mid+1..right]
	merge_sort(arr, left, mid);      // 递归调自己：让左半边有序
	merge_sort(arr, mid + 1, right); // 递归调自己：让右半边有序
	merge(arr, left, mid, right);    // 合：两边都排好了，一合并就整体有序
}
```

关键心法（克服对递归的恐惧）：

- **不要一行一行往下钻**。只记住一句承诺："调用 `merge_sort(arr, a, b)` 之后，`arr[a..b]` 就变有序了。"
- 有了这个承诺：左半边调用后左半边有序，右半边调用后右半边有序 —— 剩下的事就是把两个已经有序的段合并，`merge` 正好干这个。
- 递归必须有一个**出口**：`left >= right`。要么区间为空，要么只有一个元素，不用再分，直接返回。没有出口会无限递归、程序崩溃（栈溢出）。

以 `[5, 3]`（left=0, right=1）为例展开一次：
```
merge_sort(0,1): left<right，mid=0
 ├─ merge_sort(0,0): left>=right → 返回        （[5] 单个元素，有序）
 ├─ merge_sort(1,1): left>=right → 返回        （[3] 单个元素，有序）
 └─ merge(0,0,1): 合并 [5] 和 [3] → [3,5]      （结果就序了）
```

## 六、`merge` 逐步讲解（合并，不递归，纯逻辑）

```c
void merge(int arr[], int left, int mid, int right)
{
	int i = left;        // i 指向左半段起点
	int j = mid + 1;     // j 指向右半段起点
	int k = 0;           // k 是临时数组的下标
	int size = right - left + 1;   // 这段一共几个元素
	int* temp = (int*)malloc(size * sizeof(int));
```

前提：`arr[left..mid]` 和 `arr[mid+1..right]` **各自已经有序**。

第一步，比较复制（核心）：
```c
	while (i <= mid && j <= right) {   // 两边都还有元素时
		if (arr[i] <= arr[j]) {        // 左边那个 <= 右边那个
			temp[k++] = arr[i++];      // 拷左边，i 前进
		} else {
			temp[k++] = arr[j++];      // 否则拷右边，j 前进
		}
	}
```
- 每次取"左右两半当前最小"中更小的那个进 temp。
- `temp[k++] = arr[i++]` 语法糖：先 `temp[k] = arr[i]`，然后 `k++`、`i++`。这是 C 里常见的紧凑写法。

第二步，处理"剩饭"（某一边先走完的情况）：
```c
	while (i <= mid) {
		temp[k++] = arr[i++];   // 左边还有剩 → 全部拷过去
	}
	while (j <= right) {
		temp[k++] = arr[j++];   // 右边还有剩 → 全部拷过去
	}
```
- 两遍 while 最多只执行一个：因为从第一个 while 退出时，必然有一边走完了。
- 剩下的元素本来就是有序的，按顺序拷即可。

第三步，回写：
```c
	for (i = 0; i < size; i++) {
		arr[left + i] = temp[i];   // 把排序后的结果放回 arr 的对应位置
	}

	free(temp);                    // 释放临时空间
}
```
- `arr[left + i]`：因为合并结果要写回原位置 `arr[left..right]`，偏移就是从 left 开始。
- **必须 free**，否则每次递归都开一块、漏一块，内存越用越少。

`merge` 的时间复杂度：一趟从头走到尾，O(n)。

## 七、完整演示（从小到大数数量级最小例子）

输入 `n=5`，数组 `[5, 3, 8, 1, 9]`。边界如下：

```
merge_sort(0,4)   mid=2
├─ merge_sort(0,2)   mid=1
│  ├─ merge_sort(0,1)   mid=0
│  │  ├─ merge_sort(0,0)  → 返回
│  │  ├─ merge_sort(1,1)  → 返回
│  │  └─ merge(0,0,1): [5][3] → [3,5]
│  ├─ merge_sort(2,2)  → 返回
│  └─ merge(0,1,2): [3,5][8] → [3,5,8]
├─ merge_sort(3,4)   mid=3
│  ├─ merge_sort(3,3)  → 返回
│  ├─ merge_sort(4,4)  → 返回
│  └─ merge(3,3,4): [1][9] → [1,9]
└─ merge(0,2,4): [3,5,8][1,9] → [1,3,5,8,9]
```

最终输出：`1 3 5 8 9`。

## 八、容易踩的坑（考试/出 bug 高发点）

1. **递归出口忘记写 / 写错** → 无限递归，程序崩。
2. **`mid` 的位置**：左半边是 `[left..mid]`，右半边是 `[mid+1..right]`，`mid` 别两边重复包含。合并时 `j` 从 `mid+1` 起。
3. **临时数组大小算错**：是 `right - left + 1`，不是 `right - left`。
4. **拷回时坐标**：写回 `arr[left + i]`，不是 `arr[i]`。`temp` 的 0 号元素对应 `arr[left]`。
5. **忘记 free**：malloc 多少就要 free 多少。
6. **malloc 失败没检查**：`arr == NULL` 时空指针访问会崩。
7. **`temp[k++] = arr[i++]` 读法**：先存取、后自增，方向别搞反。
8. **数组传参是传地址**：在函数里 `arr` 的修改，外面能看到，所以 `merge` 不用返回值。

## 九、复杂度（面试/考试背下来）

| 指标 | 值 | 说明 |
|---|---|---|
| 最好/最坏/平均时间复杂度 | O(n log n) | 每次都分两半（log n 层），每层合并总代价 O(n) |
| 空间复杂度 | O(n) | 每层合并需要临时数组，最大一层是 O(n) |
| 稳定性 | 稳定 | `arr[i] <= arr[j]` 用 `<=`，相等时左边先走，相对顺序不破坏 |
